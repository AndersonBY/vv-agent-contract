# vv-agent-contract

Language-neutral observable behavior, canonical fixtures and strict wire schemas
for vv-agent. Contract 41.0.3 refreshes the deterministic S1 producer evidence baseline. Python adoption is pending. The W3
level-3 execution worker values retain their allocation status. Rust stays
frozen at verified 23.0.0 / 0.21.x. See [the changelog](CHANGELOG.md).

Implementations pin exact version, revision, artifact and manifest digests in
contract.lock.json. Vendored fixtures are generated by snapshot tooling; shared
changes begin here and require real-producer and full-gate evidence. HEAD contains
one current shape; Git retains history.

```bash
python3 scripts/contractctl.py validate
node scripts/verify_jcs.mjs
python3 -m unittest discover -s tests
python3 scripts/contractctl.py build --output-dir dist
```
